# Холодные звонки — личная CRM для iPhone

SwiftUI + SwiftData, iOS 17+ (Liquid Glass на iOS 26+). Все данные — только на телефоне.

## Что умеет
- Цель дня: сколько звонков, сколько разговоров, сколько лидов — задаёте сами (экран «Сегодня» → кольцо).
- Быстрые кнопки «Недозвон / Отказ / Разговор» — один тап на звонок. «Лид» и «Записать звонок» открывают форму с заметкой.
- Под каждым звонком — результат и заметка; тап по звонку открывает редактирование.
- Звонок с результатом «Лид» сам создаёт карточку лида в CRM (или привязывается к лиду с тем же номером).
- Лиды: поиск, статусы (Новый → В работе → Встреча → КП → Сделка / Потерян), сумма, дата следующего контакта, история звонков, кнопки «Позвонить» и WhatsApp.
- Итоги за 7/30 дней: график, конверсии, дни с выполненной целью.
- Экспорт звонков и лидов в CSV (Excel / Numbers / Google Таблицы).

## Как получить IPA

### Вариант A — без Mac (через GitHub, бесплатно)
1. Создайте репозиторий на github.com и загрузите в него ВСЁ содержимое этой папки (включая скрытую папку `.github`).
2. Вкладка **Actions → Build IPA → Run workflow**. Через 5–10 минут внизу страницы запуска появится артефакт **ColdCallCRM-ipa** — скачайте и распакуйте, внутри `ColdCallCRM.ipa`.
3. IPA собирается без подписи — её нужно подписать своим Apple ID при установке:
   - **Sideloadly** (Windows/Mac): подключите iPhone кабелем, перетащите `.ipa`, введите Apple ID.
   - или **AltStore / SideStore**.
4. На iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** (включить, перезагрузить) → Настройки → Основные → VPN и управление устройством → доверять своему Apple ID.

С бесплатным Apple ID приложение работает 7 дней, потом его нужно переподписать (переустановить поверх — данные сохраняются). С платным аккаунтом разработчика ($99/год) — год, плюс TestFlight.

### Вариант Б — с Mac
```
brew install xcodegen
xcodegen generate
open ColdCallCRM.xcodeproj
```
В Xcode 26: выберите свой iPhone → Signing & Capabilities → ваш Team → **Run**. Установка идёт напрямую.

## Подстройка
- Что считать «разговором» — `CallOutcome.isConversation` в `Models.swift`.
- Цвета — `Palette` в `Theme.swift`.
- Bundle ID — `project.yml`. Если Sideloadly ругается на занятый ID — поменяйте на свой.
